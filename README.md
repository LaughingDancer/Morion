## Установка

Для установки приложения необходимо скачать последний релиз, доступный во вкладке [**Releases**](https://github.com/your-repo/releases).

---

## Установка пакетов

После установки необходимо:
1. Открыть **Управление пакетами NuGet**.
2. Восстановить и обновить все пакеты.

---

## Настройка

- Файл `DB.cs` отвечает за взаимодействие с базой данных. Измените параметры подключения в соответствии с архитектурой вашей базы данных.
- В классах `Авторизация.cs`, `UC_Главная.cs` и `ДобавлениеПерсонал.cs` настройте параметры подключения к почте.
- Все пользовательские элементы управления и формы взаимодействуют с базой данных. При необходимости отредактируйте SQL-запросы в соответствии с вашей архитектурой.
